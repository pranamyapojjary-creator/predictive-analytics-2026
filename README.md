# Predictive Analytics Using Historical Data

## Project Overview
This project uses historical sales data to predict future sales
trends using a Linear Regression model.

## Objectives
- Clean and preprocess historical data.
- Build a predictive regression model.
- Evaluate model performance.
- Visualize historical and predicted sales.
- Forecast sales for the next six months.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Methodology
1. Create and clean historical sales data.
2. Convert dates and sales values into suitable formats.
3. Split the data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate predictions using MAE, RMSE, and R-squared.
6. Forecast future sales.
7. Visualize the results.

## Project Outputs
- Historical sales dataset
- Future sales predictions
- Sales prediction graph
- Model evaluation metrics

## Expected Outcome
The project demonstrates predictive modeling, trend analysis,
and data-driven sales forecasting.

## Disclaimer
The included dataset is sample data for demonstration purposes.
Predictions are illustrative and should not be treated as
verified business forecasts.
